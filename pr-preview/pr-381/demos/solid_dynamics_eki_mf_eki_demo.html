Solid-dynamics EKI and MF-EKI benchmark#

This example uses the nonlinear cantilever in the solid dynamics model as a controlled inverse problem for comparing single-fidelity ensemble Kalman inversion (EKI) and multifidelity EKI (MF-EKI). The first benchmark intentionally changes only numerical resolution between the high- and low-fidelity models; both use the same compressible Neo-Hookean physics. This makes it possible to study the effect of fidelity correlation without introducing model-form error at the same time.

Inverse parameters#

The unknown physical parameters are Young’s modulus, Poisson’s ratio, and the amplitude of the transient end load,

\[\theta = (E,\nu,F_0).\]

Positive parameters are represented internally in logarithmic coordinates,

\[\xi = (\log E,\nu,\log F_0),\]

which keeps the EKI updates well scaled and guarantees positive values when the model maps back to physical units. The prior ranges are

\[E \in [0.6,1.4]\ \mathrm{MPa},\qquad \nu \in [0.20,0.40],\qquad F_0 \in [700,1300]\ \mathrm{N}.\]

The synthetic truth is deliberately away from the center of these ranges,

\[E^*=1.15\ \mathrm{MPa},\qquad \nu^*=0.33,\qquad F_0^*=900\ \mathrm{N}.\]

Observation model#

The beam is clamped on the left and driven by the same smooth half-sine transient used in the solid-dynamics cantilever example. The observation vector concatenates transverse-displacement histories at

\[x/L = 0.50,\ 0.75,\ 1.00,\]

sampled every 0.1 s from 0.1 through 1.0 s. Synthetic data are generated on the truth discretization and perturbed with reproducible Gaussian noise. A single standard deviation equal to one percent of the largest clean observed displacement is used for the initial benchmark,

\[y = \mathcal G_{\mathrm{truth}}(\theta^*) + \eta, \qquad \eta\sim\mathcal N(0,\sigma_{\mathrm{obs}}^2 I).\]

The truth discretization is finer than the inference high-fidelity model, so the inverse problem does not use exactly the same discrete model to generate and fit the observations.

The MF-EKI low-fidelity model is passed through the normal QoiModelBuilderWithTrainingData-style interface, but the builder returns a fixed coarse discretization rather than learning a ROM from the high-fidelity snapshots. This is deliberate: the benchmark first asks how MF-EKI behaves when the low-fidelity error is ordinary spatial/temporal discretization error. A later experiment can replace the coarse Neo-Hookean model with linear elasticity to introduce controlled model-form error.

Cost metric#

Every model evaluation stores both its wall-clock time and a deterministic work proxy

\[W \propto N_{\mathrm{elem}}N_{\mathrm{step}}.\]

The high-fidelity model has unit cost and the low-fidelity evaluations are weighted by their ratio to the high-fidelity work proxy. The main comparison therefore plots observation error against cumulative HF-equivalent work. Wall-clock totals are also written to the summary JSON for reference, but they are not used as the primary algorithmic metric because they are machine dependent.

Pilot correlation#

Before the full solve, the example can evaluate a small pilot ensemble on the high- and low-fidelity models and report componentwise HF/LF QoI correlations. This provides a direct diagnostic for whether the coarse model is useful to MF-EKI. The example reports the minimum, median, and maximum correlation across all sensor/time components.

Running the benchmark#

Run the full study with

python examples/solid_dynamics_eki_mf_eki/example.py

A reduced configuration is available for CI:

python examples/solid_dynamics_eki_mf_eki/example.py --smoke

The script writes

  • solid_dynamics_observations.png for the clean/noisy sensor histories;

  • solid_dynamics_parameter_convergence.png for the EKI and MF-EKI parameter estimates;

  • solid_dynamics_error_vs_cost.png for convergence versus HF-equivalent work; and

  • solid_dynamics_eki_mf_eki_summary.json containing the truth, final estimates, pilot correlations, nominal costs, and wall-clock totals.

 46@dataclass(frozen=True)
 47class Discretization:
 48    nx: int
 49    ny: int
 50    dt: float
 51    t_end: float
 52
 53    @property
 54    def num_steps(self) -> int:
 55        return int(round(self.t_end / self.dt))

117class CantileverInverseQoiModel:
118    """Parameterized cantilever returning concatenated sensor displacement histories."""
119
120    def __init__(
121        self,
122        discretization: Discretization,
123        observation_times: np.ndarray,
124        fidelity: str,
125        relative_cost: float,
126    ) -> None:
127        self.discretization = discretization
128        self.observation_times = np.asarray(observation_times, dtype=float)
129        self.fidelity = fidelity
130        self.relative_cost = float(relative_cost)
131        time_indices = np.rint(self.observation_times / discretization.dt).astype(int)
132        represented_times = time_indices * discretization.dt
133        if not np.allclose(represented_times, self.observation_times, atol=1.0e-12, rtol=0.0):
134            raise ValueError("Observation times must lie on every model time grid")
135        self._time_indices = time_indices
136
137    def _solve(self, parameter_sample: dict[str, float]) -> tuple[np.ndarray, np.ndarray]:
138        young_modulus, poisson_ratio, load_amplitude = physical_parameters(parameter_sample)
139        model = cantilever_model(
140            nx=self.discretization.nx,
141            ny=self.discretization.ny,
142            young_modulus=young_modulus,
143            poisson_ratio=poisson_ratio,
144            density=DENSITY,
145            mass_type="consistent",
146            material_model="neo_hookean",
147        )
148        edge_shape = model.boundary_force_x(
149            model.mesh.length,
150            np.array([0.0, -1.0]),
151        )
152
153        def external_force(current_time: float) -> np.ndarray:
154            if 0.0 <= current_time <= PULSE_DURATION:
155                pulse = np.sin(np.pi * current_time / PULSE_DURATION)
156                return load_amplitude * pulse * edge_shape
157            return np.zeros(model.ndof)
158
159        state = model.initial_state(external_force=external_force)
160        times, displacements, _velocities = model.solve_implicit(
161            state,
162            dt=self.discretization.dt,
163            num_steps=self.discretization.num_steps,
164            external_force=external_force,
165            newton_tolerance=1.0e-8,
166            snapshot_stride=1,
167        )
168
169        sensor_dofs = []
170        for x_fraction in SENSOR_X_OVER_L:
171            node = model.mesh.node_nearest(
172                x_fraction * model.mesh.length,
173                0.5 * model.mesh.height,
174            )
175            sensor_dofs.append(2 * node + 1)
176        sensor_dofs = np.asarray(sensor_dofs, dtype=int)
177
178        sampled = displacements[np.ix_(self._time_indices, sensor_dofs)]
179        # Store sensor-major histories: all times at x/L=0.5, then 0.75, then 1.0.
180        qoi = sampled.T.reshape(-1)
181        return times, qoi
182
183    def evaluate_qoi(self, parameter_sample: dict[str, float]) -> np.ndarray:
184        return self._solve(parameter_sample)[1]
185
186    def populate_run_directory(self, run_directory: str, parameter_sample: dict) -> None:
187        run_path = Path(run_directory)
188        run_path.mkdir(parents=True, exist_ok=True)
189        with (run_path / "params.json").open("w", encoding="utf-8") as handle:
190            json.dump(parameter_sample, handle, indent=2)
191
192    def run_model(self, run_directory: str, parameter_sample: dict) -> int:
193        start = time.perf_counter()
194        times, qoi = self._solve(parameter_sample)
195        elapsed = time.perf_counter() - start
196        np.savez(
197            Path(run_directory) / "solution.npz",
198            times=times,
199            qoi=qoi,
200            fidelity=self.fidelity,
201            relative_cost=self.relative_cost,
202            elapsed_seconds=elapsed,
203        )
204        return 0
205
206    def compute_qoi(self, run_directory: str, parameter_sample: dict) -> np.ndarray:
207        del parameter_sample
208        with np.load(Path(run_directory) / "solution.npz") as data:
209            return np.array(data["qoi"], copy=True)

245def _restart_files(work_dir: Path) -> list[Path]:
246    files = []
247    iteration = 0
248    while True:
249        path = work_dir / f"iteration_{iteration}" / "restart.npz"
250        if not path.exists():
251            break
252        files.append(path)
253        iteration += 1
254    return files

257def _parameter_history(work_dir: Path, multifidelity: bool) -> np.ndarray:
258    history = []
259    for restart in _restart_files(work_dir):
260        with np.load(restart, allow_pickle=True) as data:
261            samples = data["parameter_samples_one"] if multifidelity else data["parameter_samples"]
262            E = np.mean(np.exp(samples[:, 0]))
263            nu = np.mean(samples[:, 1])
264            F0 = np.mean(np.exp(samples[:, 2]))
265            history.append([E, nu, F0])
266    return np.asarray(history, dtype=float)

269def _error_history(work_dir: Path, multifidelity: bool) -> np.ndarray:
270    history = []
271    for restart in _restart_files(work_dir):
272        with np.load(restart, allow_pickle=True) as data:
273            if multifidelity:
274                errors = data["sample_one_fom_results"].item()["errors"]
275            else:
276                errors = data["errors"]
277            history.append(float(np.mean(np.linalg.norm(errors, axis=0))))
278    return np.asarray(history)

281def _iteration_cost_history(work_dir: Path) -> np.ndarray:
282    cumulative = []
283    running = 0.0
284    iteration = 0
285    while True:
286        iteration_dir = work_dir / f"iteration_{iteration}"
287        if not iteration_dir.exists():
288            break
289        for solution in iteration_dir.rglob("solution.npz"):
290            with np.load(solution) as data:
291                if "relative_cost" in data:
292                    running += float(data["relative_cost"])
293        cumulative.append(running)
294        iteration += 1
295    return np.asarray(cumulative)

298def _wallclock_summary(work_dir: Path) -> dict[str, float]:
299    summary: dict[str, float] = {}
300    for solution in work_dir.rglob("solution.npz"):
301        with np.load(solution) as data:
302            fidelity = str(data["fidelity"])
303            summary[fidelity] = summary.get(fidelity, 0.0) + float(data["elapsed_seconds"])
304    return summary

307def _pilot_correlations(
308    high_model: CantileverInverseQoiModel,
309    low_model: CantileverInverseQoiModel,
310    num_samples: int,
311    seed: int,
312) -> np.ndarray:
313    if num_samples <= 1:
314        return np.array([])
315    rng = np.random.default_rng(seed)
316    high_qois = []
317    low_qois = []
318    for _ in range(num_samples):
319        sample = {
320            "log_E": rng.uniform(np.log(E_RANGE[0]), np.log(E_RANGE[1])),
321            "nu": rng.uniform(*NU_RANGE),
322            "log_F0": rng.uniform(np.log(F0_RANGE[0]), np.log(F0_RANGE[1])),
323        }
324        high_qois.append(high_model.evaluate_qoi(sample))
325        low_qois.append(low_model.evaluate_qoi(sample))
326    high_qois = np.asarray(high_qois)
327    low_qois = np.asarray(low_qois)
328    correlations = []
329    for column in range(high_qois.shape[1]):
330        if np.std(high_qois[:, column]) == 0.0 or np.std(low_qois[:, column]) == 0.0:
331            continue
332        correlations.append(np.corrcoef(high_qois[:, column], low_qois[:, column])[0, 1])
333    return np.asarray(correlations)

336def _plot_truth(observation_times: np.ndarray, clean: np.ndarray, noisy: np.ndarray, output: Path) -> None:
337    fig, ax = plt.subplots(figsize=(7.0, 4.2))
338    n_times = observation_times.size
339    for i, x_fraction in enumerate(SENSOR_X_OVER_L):
340        sl = slice(i * n_times, (i + 1) * n_times)
341        ax.plot(observation_times, clean[sl], label=f"truth x/L={x_fraction:.2f}")
342        ax.plot(observation_times, noisy[sl], "o", ms=3, alpha=0.65)
343    ax.set_xlabel("Time [s]")
344    ax.set_ylabel("Transverse displacement [m]")
345    ax.set_title("Synthetic cantilever observations")
346    ax.grid(True, alpha=0.25)
347    ax.legend()
348    fig.tight_layout()
349    fig.savefig(output, dpi=180)
350    plt.close(fig)

403def main(smoke: bool = False, work_dir: str | None = None, output_dir: str | None = None) -> None:
404    cfg = configuration(smoke)
405    base_dir = Path(work_dir) if work_dir is not None else EXAMPLE_DIR / "work"
406    figures_dir = Path(output_dir) if output_dir is not None else EXAMPLE_DIR
407    figures_dir.mkdir(parents=True, exist_ok=True)
408    shutil.rmtree(base_dir, ignore_errors=True)
409    base_dir.mkdir(parents=True, exist_ok=True)
410
411    hf_reference_work = cfg.high.work_proxy
412    truth_model = CantileverInverseQoiModel(
413        cfg.truth,
414        cfg.observation_times,
415        fidelity="truth",
416        relative_cost=cfg.truth.work_proxy / hf_reference_work,
417    )
418    high_model = CantileverInverseQoiModel(
419        cfg.high,
420        cfg.observation_times,
421        fidelity="high",
422        relative_cost=1.0,
423    )
424    low_model = CantileverInverseQoiModel(
425        cfg.low,
426        cfg.observation_times,
427        fidelity="low",
428        relative_cost=cfg.low.work_proxy / hf_reference_work,
429    )
430
431    truth_sample = transformed_sample(**TRUTH)
432    clean_observations = truth_model.evaluate_qoi(truth_sample)
433    noise_sigma = 0.01 * max(float(np.max(np.abs(clean_observations))), 1.0e-8)
434    rng = np.random.default_rng(17)
435    observations = clean_observations + rng.normal(0.0, noise_sigma, clean_observations.shape)
436    observations_covariance = np.eye(observations.size) * noise_sigma**2
437
438    correlations = _pilot_correlations(
439        high_model,
440        low_model,
441        cfg.pilot_samples,
442        seed=23,
443    )
444    if correlations.size:
445        print(
446            "Pilot HF/LF QoI correlation: "
447            f"median={np.median(correlations):.4f}, min={np.min(correlations):.4f}, "
448            f"max={np.max(correlations):.4f}"
449        )
450
451    lower, upper = parameter_bounds()
452    space = parameter_space()
453    eki_dir = base_dir / "eki"
454    mf_dir = base_dir / "mf_eki"
455
456    solver_args = dict(
457        initial_step_size=0.05,
458        regularization_parameter=1.0e-4,
459        step_size_growth_factor=1.25,
460        step_size_decay_factor=2.0,
461        max_step_size_decrease_trys=5,
462        relaxation_parameter=1.05,
463        error_norm_tolerance=1.0e-5,
464        delta_params_tolerance=1.0e-6,
465        max_iterations=cfg.max_iterations,
466        random_seed=5,
467    )
468
469    run_eki(
470        model=high_model,
471        parameter_space=space,
472        observations=observations,
473        observations_covariance=observations_covariance,
474        parameter_mins=lower,
475        parameter_maxes=upper,
476        absolute_work_dir=str(eki_dir),
477        ensemble_size=cfg.eki_ensemble_size,
478        evaluation_concurrency=1,
479        **solver_args,
480    )
481
482    run_mf_eki(
483        model=high_model,
484        rom_model_builder=FixedLowFidelityBuilder(low_model),
