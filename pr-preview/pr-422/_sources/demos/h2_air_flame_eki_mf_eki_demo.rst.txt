H2-air flame EKI and MF-EKI
===========================

**Method.** EKI updates an ensemble of parameter estimates from model observations. Adaptive rejuvenation can restore ensemble diversity when updates stagnate.

**Example.** The example compares standard and rejuvenated EKI and GP-assisted MF-EKI for four parameters of a two-dimensional H2-air flame model.

Run: ``python examples/h2_air_flame_eki_mf_eki/example.py``.

For algorithm details, settings, and full source listings, see
:doc:`h2_air_flame_eki_mf_eki_demo_details`.
