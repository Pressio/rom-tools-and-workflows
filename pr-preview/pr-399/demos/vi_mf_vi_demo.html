Analytic sine VI and MF-VI examples#

These examples use the analytically tractable sine-series inverse problem from the VI/MF-VI benchmark. The forward model is

\[u''(x)=f(x;\theta), \qquad u(0)=u(1)=0,\]

with

\[f(x;\theta)=\sum_{j=1}^{7}\theta_j\sin(j\pi x),\]

so the exact solution is

\[u(x;\theta) =-\sum_{j=1}^{7}\frac{\theta_j}{(j\pi)^2}\sin(j\pi x).\]

The prior is

\[\theta \sim \mathcal N(0,0.75^2 I),\]

with synthetic truth

\[\theta^\star =(1.00,-0.80,0.65,-0.50,0.35,-0.25,0.15)^T,\]

and observation-noise standard deviation \(\sigma_\eta=5\times10^{-3}\). Because the forward map is linear and the prior and likelihood are Gaussian, the exact posterior is available in closed form,

\[C_{\rm post}^{-1} = C_0^{-1}+G^T\Gamma_{\rm obs}^{-1}G,\]
\[m_{\rm post} = C_{\rm post} \left(C_0^{-1}m_0+G^T\Gamma_{\rm obs}^{-1}y\right).\]

This lets both examples measure convergence directly against the exact posterior.

Shared optimization configuration#

Both examples compare single-fidelity VI with MF-VI using the automatic Gaussian-process ROM. The production runs use the same optimizer settings:

optimizer = VINewtonOptimizerConfig(
    newton_metric="natural",
    newton_regularization=1e-4,
    gradient_norm_tolerance=0.0,
    max_iterations=max_iterations,
)

line_search = VIStochasticNonmonotoneLineSearchConfig(
    max_step_size=1.0,
)

The shared VI/MF-VI arguments explicitly use the joint entropy estimator and a leave-one-out baseline:

common_arguments = dict(
    ...,
    optimizer_method="newton",
    optimizer_config=optimizer,
    line_search_method="stochastic_nonmonotone",
    line_search_config=line_search,
    baseline_method="loo",
    score_function_entropy_strategy="joint",
)

The full runs use 16 FOM samples per iteration. MF-VI uses the automatic GP ROM with four iterations of training history:

workflows.mf_vi_with_auto_rom(
    ...,
    fom_sample_size=16,
    max_rom_training_history=4,
    rom_type="gp",
)

prior_parameter_space defines the Bayesian prior, while the required initial_variational_parameter_space independently selects the variational family and supplies its initial moments.

Example 1: equispaced observations and a diagonal posterior#

The first example uses \(N=31\) equispaced interior observations,

\[x_i=\frac{i}{N+1}, \qquad i=1,\ldots,N.\]

For these points the discrete sine basis is orthogonal, so \(G^T\Gamma_{\rm obs}^{-1}G\) is diagonal. Since the prior covariance is also diagonal, the exact posterior covariance is diagonal to numerical precision.

The variational initializer is a GaussianParameterSpace. This selects the diagonal/mean-field VI implementation.

Run the example with

python examples/vi_mf_vi_demo/diagonal_example.py

Convergence#

The convergence plot reports the exact Gaussian \(D_{\rm KL}(q\|p_{\rm post})\) for the accepted VI and MF-VI states.

Example 2: non-equispaced observations and a correlated posterior#

The second example keeps the same model, prior, truth, noise level, and number of observations, but changes only the observation locations. Starting from

\[t_i=\frac{i}{N+1},\]

the locations are warped according to

\[x_i =0.02+0.96\,\frac{t_i^3}{t_N^3}.\]

This breaks discrete sine orthogonality. The exact posterior therefore has nonzero cross-covariances (the largest absolute posterior correlation is about 0.30 for this setup).

The prior remains the same diagonal GaussianParameterSpace. The variational initializer is instead a MultivariateGaussianParameterSpace initialized with the same diagonal prior covariance. Its type selects true full-covariance VI, allowing off-diagonal covariance entries to develop during optimization.

This case uses the same natural-coordinate Newton configuration as the diagonal case. For the full-covariance family, Newton curvature is formed in \((\mu,\operatorname{svec}(\Sigma))\) coordinates and locally whitened with the exact Gaussian Fisher metric before the regularized Newton solve. The covariance update is then applied with the SPD-preserving exponential retraction described in Full-covariance variational inference.

Run the example with

python examples/vi_mf_vi_demo/full_covariance_example.py

Shared problem definition#

The forward model, exact posterior calculation, history processing, and plotting utilities are shared by both examples:

  1"""Shared analytic sine inverse problem and plotting utilities for VI examples."""
  2
  3from __future__ import annotations
  4
  5from dataclasses import dataclass
  6from pathlib import Path
  7
  8import matplotlib.pyplot as plt
  9from matplotlib.patches import Ellipse
 10import numpy as np
 11
 12
 13DIMENSION = 7
 14N_OBSERVATIONS = 31
 15OBSERVATION_NOISE_STD = 5.0e-3
 16PRIOR_STD = 0.75
 17RANDOM_SEED = 7
 18TRUTH = np.array([1.00, -0.80, 0.65, -0.50, 0.35, -0.25, 0.15], dtype=float)
 19
 20
 21@dataclass(frozen=True)
 22class AnalyticSineProblem:
 23    """Linear-Gaussian sine-series inverse problem with an exact posterior."""
 24
 25    parameter_names: tuple[str, ...]
 26    observation_locations: np.ndarray
 27    observation_matrix: np.ndarray
 28    truth: np.ndarray
 29    observations: np.ndarray
 30    observation_covariance: np.ndarray
 31    prior_mean: np.ndarray
 32    prior_covariance: np.ndarray
 33    posterior_mean: np.ndarray
 34    posterior_covariance: np.ndarray
 35
 36
 37def _observation_locations(equispaced: bool) -> np.ndarray:
 38    indices = np.arange(1, N_OBSERVATIONS + 1, dtype=float)
 39    if equispaced:
 40        return indices / (N_OBSERVATIONS + 1)
 41
 42    # Keep the same number of observations and nearly the same spatial extent,
 43    # but cluster points toward x=0. This breaks the discrete sine
 44    # orthogonality that makes the equispaced posterior diagonal.
 45    scaled = indices / (N_OBSERVATIONS + 1)
 46    warped = scaled**3 / scaled[-1]**3
 47    return 0.02 + 0.96 * warped
 48
 49
 50def build_problem(equispaced: bool) -> AnalyticSineProblem:
 51    """Build the sine-series inverse problem and its exact Gaussian posterior."""
 52    parameter_names = tuple(f"theta_{j}" for j in range(1, DIMENSION + 1))
 53    x = _observation_locations(equispaced)
 54    modes = np.arange(1, DIMENSION + 1, dtype=float)
 55    observation_matrix = -np.sin(np.pi * np.outer(x, modes)) / (
 56        np.pi * modes[None, :]
 57    ) ** 2
 58
 59    prior_mean = np.zeros(DIMENSION, dtype=float)
 60    prior_covariance = np.eye(DIMENSION) * PRIOR_STD**2
 61    observation_covariance = np.eye(N_OBSERVATIONS) * OBSERVATION_NOISE_STD**2
 62
 63    rng = np.random.default_rng(RANDOM_SEED)
 64    observations = (
 65        observation_matrix @ TRUTH
 66        + OBSERVATION_NOISE_STD * rng.standard_normal(N_OBSERVATIONS)
 67    )
 68
 69    prior_precision = np.linalg.inv(prior_covariance)
 70    observation_precision = np.linalg.inv(observation_covariance)
 71    posterior_precision = (
 72        prior_precision
 73        + observation_matrix.T @ observation_precision @ observation_matrix
 74    )
 75    posterior_covariance = np.linalg.inv(posterior_precision)
 76    posterior_mean = posterior_covariance @ (
 77        prior_precision @ prior_mean
 78        + observation_matrix.T @ observation_precision @ observations
 79    )
 80
 81    off_diagonal = posterior_covariance - np.diag(np.diag(posterior_covariance))
 82    if equispaced:
 83        scale = max(float(np.max(np.diag(posterior_covariance))), 1.0e-16)
 84        if np.max(np.abs(off_diagonal)) / scale > 1.0e-10:
 85            raise RuntimeError("Expected the equispaced posterior covariance to be diagonal.")
 86    else:
 87        correlation = covariance_to_correlation(posterior_covariance)
 88        correlation_off_diagonal = correlation - np.eye(DIMENSION)
 89        if np.max(np.abs(correlation_off_diagonal)) < 0.1:
 90            raise RuntimeError("Non-equispaced observations did not create meaningful correlation.")
 91
 92    return AnalyticSineProblem(
 93        parameter_names=parameter_names,
 94        observation_locations=x,
 95        observation_matrix=observation_matrix,
 96        truth=TRUTH.copy(),
 97        observations=observations,
 98        observation_covariance=observation_covariance,
 99        prior_mean=prior_mean,
100        prior_covariance=prior_covariance,
101        posterior_mean=posterior_mean,
102        posterior_covariance=posterior_covariance,
103    )
104
105
106class AnalyticSineQoiModel:
107    """ROMTools QoI model evaluating the exact sine-series solution."""
108
109    def __init__(self, problem: AnalyticSineProblem):
110        self.problem = problem
111
112    def _theta(self, parameter_sample: dict) -> np.ndarray:
113        return np.array(
114            [float(parameter_sample[name]) for name in self.problem.parameter_names],
115            dtype=float,
116        )
117
118    def populate_run_directory(self, run_directory: str, parameter_sample: dict) -> None:
119        del parameter_sample
120        Path(run_directory).mkdir(parents=True, exist_ok=True)
121
122    def run_model(self, run_directory: str, parameter_sample: dict) -> int:
123        qoi = self.problem.observation_matrix @ self._theta(parameter_sample)
124        np.save(Path(run_directory) / "qoi.npy", qoi)
125        return 0
126
127    def compute_qoi(self, run_directory: str, parameter_sample: dict) -> np.ndarray:
128        del parameter_sample
129        return np.load(Path(run_directory) / "qoi.npy")

132def gaussian_kl(
133    mean: np.ndarray,
134    covariance: np.ndarray,
135    reference_mean: np.ndarray,
136    reference_covariance: np.ndarray,
137) -> float:
138    """Return KL[N(mean,covariance) || N(reference_mean,reference_covariance)]."""
139    mean = np.asarray(mean, dtype=float)
140    covariance = np.asarray(covariance, dtype=float)
141    reference_mean = np.asarray(reference_mean, dtype=float)
142    reference_covariance = np.asarray(reference_covariance, dtype=float)
143
144    dimension = mean.size
145    delta = reference_mean - mean
146    sign_q, logdet_q = np.linalg.slogdet(covariance)
147    sign_p, logdet_p = np.linalg.slogdet(reference_covariance)
148    if sign_q <= 0 or sign_p <= 0:
149        return float("inf")
150    solve_covariance = np.linalg.solve(reference_covariance, covariance)
151    solve_delta = np.linalg.solve(reference_covariance, delta)
152    return float(
153        0.5
154        * (
155            np.trace(solve_covariance)
156            + delta @ solve_delta
157            - dimension
158            + logdet_p
159            - logdet_q
160        )
161    )
162

164def collect_history(work_dir: Path, problem: AnalyticSineProblem) -> dict[str, np.ndarray]:
165    """Read the accepted VI states and prepend the common initial state."""
166    with np.load(work_dir / "history.npz") as history:
167        means = np.asarray(history["vi_history_variational_mean"], dtype=float)
168        covariances = np.asarray(
169            history["vi_history_variational_covariance"], dtype=float
170        )
171
172    if (
173        means.shape[0] == 0
174        or not np.allclose(means[0], problem.prior_mean)
175        or not np.allclose(covariances[0], problem.prior_covariance)
176    ):
177        means = np.concatenate([problem.prior_mean[None, :], means], axis=0)
178        covariances = np.concatenate(
179            [problem.prior_covariance[None, :, :], covariances], axis=0
180        )
181
182    kl = np.asarray(
183        [
184            gaussian_kl(
185                mean,
186                covariance,
187                problem.posterior_mean,
188                problem.posterior_covariance,
189            )
190            for mean, covariance in zip(means, covariances)
191        ],
192        dtype=float,
193    )
194    return {"mean": means, "covariance": covariances, "kl": kl}
195
196
197def covariance_to_correlation(covariance: np.ndarray) -> np.ndarray:
198    standard_deviations = np.sqrt(np.maximum(np.diag(covariance), 0.0))
199    denominator = np.outer(standard_deviations, standard_deviations)
200    correlation = np.divide(
201        covariance,
202        denominator,
203        out=np.zeros_like(covariance, dtype=float),
204        where=denominator > 0.0,
205    )
206    np.fill_diagonal(correlation, 1.0)
207    return correlation

271def _normal_density(grid: np.ndarray, mean: float, variance: float) -> np.ndarray:
272    variance = max(float(variance), 1.0e-16)
273    return np.exp(-0.5 * (grid - mean) ** 2 / variance) / np.sqrt(
274        2.0 * np.pi * variance
275    )

279    output_path: Path,
280    problem: AnalyticSineProblem,
281    vi_history: dict[str, np.ndarray],
282    mf_history: dict[str, np.ndarray],
283) -> None:
284    """Plot one-dimensional marginals for the diagonal-posterior example."""
285    output_path.parent.mkdir(parents=True, exist_ok=True)
286    figure, axes = plt.subplots(2, 4, figsize=(12.0, 6.2))
287    final_states = (
288        ("VI", vi_history["mean"][-1], vi_history["covariance"][-1]),
289        ("MF-VI", mf_history["mean"][-1], mf_history["covariance"][-1]),
290    )
291    for index, axis in enumerate(axes.flat):
292        if index >= DIMENSION:
293            axis.axis("off")
294            continue
295        exact_mean = problem.posterior_mean[index]
296        exact_variance = problem.posterior_covariance[index, index]
297        width = 4.0 * np.sqrt(exact_variance)
298        grid = np.linspace(exact_mean - width, exact_mean + width, 300)
299        axis.plot(
300            grid,
301            _normal_density(grid, exact_mean, exact_variance),
302            linewidth=2.0,
303            label="Exact",
304        )
305        for label, mean, covariance in final_states:
306            axis.plot(
307                grid,
308                _normal_density(grid, mean[index], covariance[index, index]),
309                label=label,
310            )
311        axis.axvline(problem.truth[index], color="black", linestyle="--", linewidth=1.0)
312        axis.set_title(problem.parameter_names[index])
313        axis.grid(True, alpha=0.2)
314    axes.flat[0].legend()
315    figure.suptitle("Posterior marginal densities")
316    figure.tight_layout()
317    figure.savefig(output_path, dpi=180)
318    plt.close(figure)

321def _add_covariance_ellipse(
322    axis,
323    mean: np.ndarray,
324    covariance: np.ndarray,
325    label: str,
326    linestyle: str,
327    linewidth: float,
328) -> None:
329    eigenvalues, eigenvectors = np.linalg.eigh(covariance)
330    order = np.argsort(eigenvalues)[::-1]
331    eigenvalues = eigenvalues[order]
332    eigenvectors = eigenvectors[:, order]
333    angle = np.degrees(np.arctan2(eigenvectors[1, 0], eigenvectors[0, 0]))
334    for scale in (1.0, 2.0):
335        ellipse = Ellipse(
336            xy=mean,
337            width=2.0 * scale * np.sqrt(max(eigenvalues[0], 0.0)),
338            height=2.0 * scale * np.sqrt(max(eigenvalues[1], 0.0)),
339            angle=angle,
340            fill=False,
341            linestyle=linestyle,
342            linewidth=linewidth,
343            label=label if scale == 1.0 else None,
344        )
345        axis.add_patch(ellipse)

348def write_correlated_posterior_plot(
349    output_path: Path,
350    problem: AnalyticSineProblem,
351    vi_history: dict[str, np.ndarray],
352    mf_history: dict[str, np.ndarray],
353) -> None:
354    """Show posterior correlation and a two-dimensional Gaussian marginal."""
355    output_path.parent.mkdir(parents=True, exist_ok=True)
356    exact_correlation = covariance_to_correlation(problem.posterior_covariance)
357    off_diagonal = np.abs(exact_correlation - np.eye(DIMENSION))
358    first, second = np.unravel_index(np.argmax(off_diagonal), off_diagonal.shape)
359    pair = np.array([first, second], dtype=int)
360
361    figure, axes = plt.subplots(1, 2, figsize=(11.5, 4.6))
362    image = axes[0].imshow(exact_correlation, vmin=-1.0, vmax=1.0, cmap="coolwarm")
363    axes[0].set(
364        title="Exact posterior correlation",
365        xlabel="Parameter index",
366        ylabel="Parameter index",
367        xticks=np.arange(DIMENSION),
368        yticks=np.arange(DIMENSION),
369        xticklabels=np.arange(1, DIMENSION + 1),
370        yticklabels=np.arange(1, DIMENSION + 1),
371    )
372    figure.colorbar(image, ax=axes[0], fraction=0.046, pad=0.04)
373
374    exact_mean = problem.posterior_mean[pair]
375    exact_covariance = problem.posterior_covariance[np.ix_(pair, pair)]
376    _add_covariance_ellipse(
377        axes[1], exact_mean, exact_covariance, "Exact", "-", 2.2
378    )
379    _add_covariance_ellipse(
380        axes[1],
381        vi_history["mean"][-1, pair],
382        vi_history["covariance"][-1][np.ix_(pair, pair)],
383        "VI",
384        "--",
385        1.8,
386    )
387    _add_covariance_ellipse(
388        axes[1],
389        mf_history["mean"][-1, pair],
390        mf_history["covariance"][-1][np.ix_(pair, pair)],
391        "MF-VI",
392        ":",
393        2.0,
394    )
395    axes[1].plot(
396        problem.truth[first],
397        problem.truth[second],
398        "kx",
399        markersize=8,
400        label="Truth",
401    )
402
403    all_means = np.vstack(
404        [
405            exact_mean,
406            vi_history["mean"][-1, pair],
407            mf_history["mean"][-1, pair],
408        ]
409    )
410    max_std = max(
411        np.sqrt(np.max(np.linalg.eigvalsh(exact_covariance))),
412        np.sqrt(
413            np.max(
414                np.linalg.eigvalsh(
415                    vi_history["covariance"][-1][np.ix_(pair, pair)]
416                )
417            )
418        ),
419        np.sqrt(
420            np.max(
421                np.linalg.eigvalsh(
422                    mf_history["covariance"][-1][np.ix_(pair, pair)]
423                )
424            )
425        ),
426    )
427    lower = np.min(all_means, axis=0) - 3.0 * max_std
428    upper = np.max(all_means, axis=0) + 3.0 * max_std
429    axes[1].set_xlim(lower[0], upper[0])
430    axes[1].set_ylim(lower[1], upper[1])
431    axes[1].set(
432        title=(
433            f"Strongest correlated marginal "
434            f"(rho={exact_correlation[first, second]:.2f})"
435        ),
436        xlabel=problem.parameter_names[first],
437        ylabel=problem.parameter_names[second],
438    )
439    axes[1].grid(True, alpha=0.25)
440    axes[1].legend()
441
442    figure.suptitle("Full-covariance posterior structure")
443    figure.tight_layout()
444    figure.savefig(output_path, dpi=180)
445    plt.close(figure)
