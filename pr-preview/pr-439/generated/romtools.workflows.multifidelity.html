romtools.workflows.multifidelity#

Fixed-allocation random adaptive training for ordered multifidelity QoI models.

This first workflow intentionally keeps fidelity allocation fixed. All model evaluations use the existing blocking/nonblocking execution abstraction.

class romtools.workflows.multifidelity.MultiFidelityKFoldValidation(num_folds=5)[source]#

Bases: object

K-fold CV of the highest fidelity, retaining all lower-level data.

Lower-fidelity data at held-out high-fidelity locations remain available: CV assesses HF prediction when inexpensive evaluations are known. The result is the maximum per-sample held-out relative L2 error, consistent with ROMtools’ existing KFoldValidation.

romtools.workflows.multifidelity.run_adaptive_multifidelity(fidelities, surrogate_builder, parameter_space, absolute_work_dir, tolerance, initial_samples, batch_sizes, *, adaptive_sampling_strategy='random', pair_fidelity_samples=True, validation_strategy=None, error_functor=<function relative_l2_error>, max_iterations=20, max_total_cost=None, max_concurrent_fom_runs=1, random_seed=1)[source]#

Build a multifidelity surrogate after each randomized sampling round.

An iteration always schedules the requested counts at every fidelity. Iteration zero uses initial_samples; subsequent rounds use batch_sizes. With pairing, every higher-fidelity location is sampled at all lower levels and per-level counts must be nonincreasing. ParameterSpace controls the underlying random sampling distribution. Costs are fixed user inputs; incomplete rounds are not automatically retried or restarted.
