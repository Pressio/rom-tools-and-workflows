romtools.workflows.inverse.eki_bound_transforms#

Bound-handling adapters for EKI and MF-EKI.

The historical EKI implementations operate directly on their input parameter ensemble. This module adds the same clip/transform choice used by VI without duplicating the EKI algorithms. In transform mode, the legacy drivers see an unconstrained optimizer-coordinate ensemble while FOM/ROM interfaces, restart files, and returned samples remain in physical coordinates.
