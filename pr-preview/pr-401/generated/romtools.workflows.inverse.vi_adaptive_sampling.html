romtools.workflows.inverse.vi_adaptive_sampling#

Adaptive small-batch sampling for Newton VI and MFVI.

The public wrappers in this module are opt-in. When adaptive_sample_config is None they delegate to the existing VI/MFVI wrapper stack unchanged. When enabled for Newton, the current Monte Carlo batch is enriched until a delete-one jackknife estimate of the covariance of the regularized Newton step is sufficiently small, or a configured maximum sample size is reached.

Configuration for jackknife-based adaptive Newton sample enrichment.

The acceptance rule is

sigma_step <= absolute_tolerance + relative_tolerance * max(||step||, step_norm_floor).

The delete-one jackknife is applied to the regularized Newton step, so the diagnostic includes model-dependent gradient variance, Hessian variance, their correlation, and (for MFVI) the fitted control-variate coefficients.
