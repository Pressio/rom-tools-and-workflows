H2-air flame model#

The examples include a self-contained, pure-Python model of a two-dimensional premixed H2-air flame. It provides a moderately challenging benchmark for romtools workflows while requiring only NumPy and SciPy.

The core solver and romtools QoI wrapper live in examples/models. A quick wrapper smoke test can be run from the repository root with

python examples/models/h2_air_flame_model.py

Problem definition#

The state contains hydrogen, oxygen, and water mass fractions together with a nondimensional temperature,

\[\boldsymbol{u} = [Y_{H_2}, Y_{O_2}, Y_{H_2O}, \theta]^T, \qquad \theta = T / T_{\mathrm{ref}},\]

on a rectangular domain of size 1.8 cm by 0.9 cm. The semi-discrete model combines advection, diffusion, and an Arrhenius reaction source. A hot premixed inlet occupies the middle third of the left boundary, with ambient Dirichlet data above and below it and homogeneous-Neumann conditions on the remaining boundaries.

The four model parameters are

kappa

Diffusivity.

scaled_activation_energy

Activation energy divided by 1000. A representative value is 8.0, corresponding to an activation energy of 8000.

beta_x and beta_y

Components of the advection velocity in cm/s. beta_x is restricted to nonnegative values because the benchmark inlet and x-upwind stencil assume left-to-right flow.

A representative parameter vector is

\[(\kappa, E/1000, \beta_x, \beta_y) = (2, 8, 40, 7).\]

The solver uses Crank-Nicolson time integration, central differences for diffusion, a second-order backward upwind stencil in the x direction, and an upwind stencil in the y direction. Newton systems are assembled and solved as SciPy sparse matrices.

Direct use#

The core solver is independent of romtools workflow interfaces. From examples/models:

from h2_air_flame import H2AirFlame

model = H2AirFlame(
    nx=25,
    ny=13,
    dt=1.0e-4,
    t_end=5.0e-3,
    snapshot_stride=10,
)
states, times = model.solve(
    kappa=2.0,
    scaled_activation_energy=8.0,
    beta_x=40.0,
    beta_y=7.0,
)

states has shape (num_snapshots, 4, nx, ny). The temperature field is stored as theta = T / 300 K so that the four state components remain on a more useful scale for reduced-order modeling. Dimensional temperature is therefore 300 * states[:, 3].

QoI model for romtools workflows#

H2AirFlameQoiModel provides the standard romtools model protocol. It uses regularly strided temperature sensors as the QoI and writes both the QoI and full state history to each run directory. Saving the state history allows the same FOM evaluations to be reused later by state-based ROM builders.

from h2_air_flame_model import H2AirFlameQoiModel

qoi_model = H2AirFlameQoiModel(
    nx=25,
    ny=13,
    dt=1.0e-4,
    t_end=5.0e-3,
    snapshot_stride=10,
    spatial_sensor_stride=4,
)

sample = {
    "kappa": 2.0,
    "scaled_activation_energy": 8.0,
    "beta_x": 40.0,
    "beta_y": 7.0,
}

qoi_model.populate_run_directory("run_0", sample)
qoi_model.run_model("run_0", sample)
qoi = qoi_model.compute_qoi("run_0", sample)

This wrapper can be passed directly to romtools workflows that consume a QoI model.

Computational cost#

The default constructor values are intended to be lightweight enough for interactive experimentation. Increasing the spatial resolution or time horizon, or reducing the time step, increases the cost of the implicit nonlinear solve. Benchmark studies should therefore report model-evaluation counts together with wall-clock cost when comparing algorithms.

 17
 18    The state ordering is ``[Y_H2, Y_O2, Y_H2O, theta]``, where
 19    ``theta = T / temperature_scale``. The four model parameters are the

 21    advection-velocity components ``beta_x`` and ``beta_y``.

 24    ----------

 27        points.

 32    snapshot_stride:
 33        Number of time steps between stored snapshots. The initial and final
 34        states are always stored.

 36        Newton convergence tolerances for each implicit time step.
 37    newton_max_iterations:
 38        Maximum Newton iterations per time step.
 39    """

 44    def __init__(
 45        self,
 46        nx: int = 25,
 47        ny: int = 13,
 48        dt: float = 1.0e-4,
 49        t_end: float = 5.0e-3,
 50        snapshot_stride: int = 10,
 51        newton_relative_tolerance: float = 1.0e-6,
 52        newton_absolute_tolerance: float = 1.0e-10,
 53        newton_max_iterations: int = 80,
 54    ) -> None:
 55        if nx < 4:
 56            raise ValueError("nx must be at least 4 for the x-upwind stencil")
 57        if ny < 3:
 58            raise ValueError("ny must be at least 3")
 59        if dt <= 0.0:
 60            raise ValueError("dt must be positive")
 61        if t_end <= 0.0:
 62            raise ValueError("t_end must be positive")
 63        if snapshot_stride < 1:
 64            raise ValueError("snapshot_stride must be at least 1")
 65        if newton_relative_tolerance <= 0.0 or newton_absolute_tolerance < 0.0:
 66            raise ValueError(
 67                "Newton tolerances must be nonnegative and rtol must be positive"
 68            )
 69        if newton_max_iterations < 1:
 70            raise ValueError("newton_max_iterations must be at least 1")
 71
 72        n_steps_float = t_end / dt
 73        n_steps = int(round(n_steps_float))
 74        if not np.isclose(n_steps_float, n_steps, rtol=0.0, atol=1.0e-12):
 75            raise ValueError("t_end must be an integer multiple of dt")
 76
 77        self.nx = int(nx)
 78        self.ny = int(ny)
 79        self.dt = float(dt)
 80        self.t_end = float(t_end)
 81        self.snapshot_stride = int(snapshot_stride)
 82        self.newton_relative_tolerance = float(newton_relative_tolerance)
 83        self.newton_absolute_tolerance = float(newton_absolute_tolerance)
 84        self.newton_max_iterations = int(newton_max_iterations)
 85        self.num_steps = n_steps
 86
 87        self.length_x = 1.8  # cm
 88        self.length_y = 0.9  # cm
 89        self.x = np.linspace(0.0, self.length_x, self.nx)
 90        self.y = np.linspace(0.0, self.length_y, self.ny)
 91        self.dx = self.x[1] - self.x[0]
 92        self.dy = self.y[1] - self.y[0]
 93
 94        self.temperature_scale = 300.0  # K
 95        self.reaction_prefactor = 4.464956898694298e12
 96        self.molecular_weights = np.array([2.016, 31.9, 18.0])  # g/mol
 97        self.density = 1.39e-3  # g/cm^3
 98        self.heat_of_reaction_scaled = 9800.0 / self.temperature_scale
 99        self.gas_constant_times_temperature_scale = 8.314472 * self.temperature_scale
100        self.stoichiometric_coefficients = np.array([2.0, 1.0, -2.0])
101
102        self.ambient_temperature = 300.0
103        self.inlet_temperature = 950.0
104        self.inlet_h2_mass_fraction = 0.0282
105        self.inlet_o2_mass_fraction = 0.2259
106        self.inlet_h2o_mass_fraction = 0.0
107
108        self._gamma_1 = self.y >= 0.6
109        self._gamma_2 = np.logical_and(self.y > 0.3, self.y < 0.6)
110        self._gamma_3 = self.y <= 0.3
111        self._reaction_mask = np.ones((self.nx, self.ny))
112        self._reaction_mask[0, :] = 0.0
113        self._reaction_mask[-1, :] = 0.0
114        self._reaction_mask[:, 0] = 0.0
115        self._reaction_mask[:, -1] = 0.0

117    def initial_state(self) -> np.ndarray:
118        """Return the initial state with boundary conditions applied."""
119        state = np.zeros((4, self.nx, self.ny))
120        state[3, :, :] = self.ambient_temperature / self.temperature_scale
121        return self.apply_boundary_conditions(state)
122
123    def apply_boundary_conditions(self, state: np.ndarray) -> np.ndarray:
124        """Apply Dirichlet inlet and homogeneous-Neumann outlet/wall conditions."""
125        if state.shape != (4, self.nx, self.ny):
126            raise ValueError(
127                "state must have shape (4, nx, ny); got {}".format(state.shape)
128            )
129
130        state[:, :, 0] = state[:, :, 1]
131        state[:, :, -1] = state[:, :, -2]
132        state[:, -1, :] = state[:, -2, :]
133
134        state[0, 0, self._gamma_1] = 0.0
135        state[1, 0, self._gamma_1] = 0.0
136        state[2, 0, self._gamma_1] = 0.0
137        state[3, 0, self._gamma_1] = self.ambient_temperature / self.temperature_scale
138
139        state[0, 0, self._gamma_2] = self.inlet_h2_mass_fraction
140        state[1, 0, self._gamma_2] = self.inlet_o2_mass_fraction
141        state[2, 0, self._gamma_2] = self.inlet_h2o_mass_fraction
142        state[3, 0, self._gamma_2] = self.inlet_temperature / self.temperature_scale
143
144        state[0, 0, self._gamma_3] = 0.0
145        state[1, 0, self._gamma_3] = 0.0
146        state[2, 0, self._gamma_3] = 0.0
147        state[3, 0, self._gamma_3] = self.ambient_temperature / self.temperature_scale
148        return state

150    def _validate_parameters(
151        self,
152        kappa: float,
153        scaled_activation_energy: float,
154        beta_x: float,
155        beta_y: float,
156    ) -> Tuple[float, float, float, float]:
157        values = np.asarray(
158            [kappa, scaled_activation_energy, beta_x, beta_y], dtype=float
159        )
160        if not np.all(np.isfinite(values)):
161            raise ValueError("model parameters must be finite")
162        if kappa <= 0.0:
163            raise ValueError("kappa must be positive")
164        if scaled_activation_energy <= 0.0:
165            raise ValueError("scaled_activation_energy must be positive")
166        if beta_x < 0.0:
167            raise ValueError(
168                "beta_x must be nonnegative because the inlet and x-upwind stencil "
169                "assume left-to-right flow"
170            )
171        return tuple(float(value) for value in values)
172
173    @staticmethod
174    def _laplacian(state: np.ndarray, dx: float, dy: float) -> np.ndarray:
175        result = np.zeros_like(state)
176        result[:, 1:-1, :] += (
177            state[:, 2:, :] - 2.0 * state[:, 1:-1, :] + state[:, :-2, :]
178        ) / dx**2
179        result[:, :, 1:-1] += (
180            state[:, :, 2:] - 2.0 * state[:, :, 1:-1] + state[:, :, :-2]
181        ) / dy**2
182        return result
183
184    @staticmethod
185    def _x_upwind_derivative(state: np.ndarray, dx: float) -> np.ndarray:
186        result = np.zeros_like(state)
187        result[:, 1:, :] = (state[:, 1:, :] - state[:, :-1, :]) / dx
188        result[:, 2:, :] = (
189            1.5 * state[:, 2:, :]
190            - 2.0 * state[:, 1:-1, :]
191            + 0.5 * state[:, :-2, :]
192        ) / dx
193        return result
194
195    @staticmethod
196    def _y_upwind_derivative(
197        state: np.ndarray, dy: float, beta_y: float
198    ) -> np.ndarray:
199        result = np.zeros_like(state)
200        if beta_y >= 0.0:
201            result[:, :, 1:] = (state[:, :, 1:] - state[:, :, :-1]) / dy
202        else:
203            result[:, :, :-1] = (state[:, :, 1:] - state[:, :, :-1]) / dy
204        return result
205
206    def _linear_rhs(
207        self, state: np.ndarray, kappa: float, beta_x: float, beta_y: float
208    ) -> np.ndarray:
209        return (
210            kappa * self._laplacian(state, self.dx, self.dy)
211            - beta_x * self._x_upwind_derivative(state, self.dx)
212            - beta_y * self._y_upwind_derivative(state, self.dy, beta_y)
213        )
214
215    def _reaction_rhs(
216        self, state: np.ndarray, scaled_activation_energy: float
217    ) -> np.ndarray:
218        theta = state[3]
219        if np.any(theta <= 0.0):
220            raise FloatingPointError("temperature became nonpositive during the solve")
221
222        rho = self.density
223        weights = self.molecular_weights
224        activation_energy = scaled_activation_energy * 1.0e3
225        exponential = np.exp(
226            -activation_energy / (self.gas_constant_times_temperature_scale * theta)
227        )
228        h2_concentration = rho * state[0] / weights[0]
229        o2_concentration = rho * state[1] / weights[1]
230        rate = (
231            h2_concentration**2
232            * o2_concentration
233            * self.reaction_prefactor
234            * exponential
235        )
236
237        reaction = np.zeros_like(state)
238        for species in range(3):
239            reaction[species] = (
240                -self.stoichiometric_coefficients[species]
241                * (weights[species] / rho)
242                * rate
243            )
244        reaction[3] = reaction[2] * self.heat_of_reaction_scaled
245        return reaction
246
247    def rhs(
248        self,
249        state: np.ndarray,
250        kappa: float,
251        scaled_activation_energy: float,
252        beta_x: float,
253        beta_y: float,
254    ) -> np.ndarray:
255        """Evaluate the semi-discrete right-hand side."""
256        kappa, scaled_activation_energy, beta_x, beta_y = self._validate_parameters(
257            kappa, scaled_activation_energy, beta_x, beta_y
258        )
259        return self._linear_rhs(state, kappa, beta_x, beta_y) + self._reaction_rhs(
260            state, scaled_activation_energy
261        )

263    def _apply_boundary_conditions_to_residual(
264        self, state: np.ndarray, residual: np.ndarray
265    ) -> np.ndarray:
266        state_view = state.reshape((4, self.nx, self.ny))
267        residual_view = residual.reshape((4, self.nx, self.ny))
268
269        residual_view[:, :, 0] = state_view[:, :, 1] - state_view[:, :, 0]
270        residual_view[:, :, -1] = state_view[:, :, -1] - state_view[:, :, -2]
271        residual_view[:, -1, :] = state_view[:, -1, :] - state_view[:, -2, :]
272
273        residual_view[0, 0, self._gamma_1] = state_view[0, 0, self._gamma_1]
274        residual_view[1, 0, self._gamma_1] = state_view[1, 0, self._gamma_1]
275        residual_view[2, 0, self._gamma_1] = state_view[2, 0, self._gamma_1]
276        residual_view[3, 0, self._gamma_1] = (
277            state_view[3, 0, self._gamma_1]
278            - self.ambient_temperature / self.temperature_scale
279        )
280
281        residual_view[0, 0, self._gamma_2] = (
282            state_view[0, 0, self._gamma_2] - self.inlet_h2_mass_fraction
283        )
284        residual_view[1, 0, self._gamma_2] = (
285            state_view[1, 0, self._gamma_2] - self.inlet_o2_mass_fraction
286        )
287        residual_view[2, 0, self._gamma_2] = (
288            state_view[2, 0, self._gamma_2] - self.inlet_h2o_mass_fraction
289        )
290        residual_view[3, 0, self._gamma_2] = (
291            state_view[3, 0, self._gamma_2]
292            - self.inlet_temperature / self.temperature_scale
293        )
294
295        residual_view[0, 0, self._gamma_3] = state_view[0, 0, self._gamma_3]
296        residual_view[1, 0, self._gamma_3] = state_view[1, 0, self._gamma_3]
297        residual_view[2, 0, self._gamma_3] = state_view[2, 0, self._gamma_3]
298        residual_view[3, 0, self._gamma_3] = (
299            state_view[3, 0, self._gamma_3]
300            - self.ambient_temperature / self.temperature_scale
301        )
302        return residual_view.reshape(-1)

304    def _residual(
305        self,
306        next_state_flat: np.ndarray,
307        previous_state: np.ndarray,
308        previous_rhs: np.ndarray,
309        kappa: float,
310        scaled_activation_energy: float,
311        beta_x: float,
312        beta_y: float,
313    ) -> np.ndarray:
314        next_state = next_state_flat.reshape((4, self.nx, self.ny))
315        next_rhs = self._linear_rhs(
316            next_state, kappa, beta_x, beta_y
317        ) + self._reaction_rhs(next_state, scaled_activation_energy)
318        residual = (
319            next_state.reshape(-1)
320            - previous_state.reshape(-1)
321            - 0.5
322            * self.dt
323            * (next_rhs.reshape(-1) + previous_rhs.reshape(-1))
324        )
325        return self._apply_boundary_conditions_to_residual(next_state_flat, residual)

327    def _build_linear_residual_jacobian(
328        self, kappa: float, beta_x: float, beta_y: float
329    ) -> scipy.sparse.csr_matrix:
330        block_size = self.nx * self.ny
331        block = scipy.sparse.lil_matrix((block_size, block_size), dtype=float)
332        dx2_inv = 1.0 / self.dx**2
333        dy2_inv = 1.0 / self.dy**2
334        dx_inv = 1.0 / self.dx
335        dy_inv = 1.0 / self.dy
336
337        def index(i: int, j: int) -> int:
338            return i * self.ny + j
339
340        for i in range(self.nx):
341            for j in range(self.ny):
342                row = index(i, j)
343                if i == 0:
344                    block[row, row] = 1.0
345                    continue
346                if i == self.nx - 1:
347                    block[row, row] = 1.0
348                    block[row, index(i - 1, j)] = -1.0
349                    continue
350                if j == 0:
351                    block[row, row] = -1.0
352                    block[row, index(i, j + 1)] = 1.0
353                    continue
354                if j == self.ny - 1:
355                    block[row, row] = 1.0
356                    block[row, index(i, j - 1)] = -1.0
357                    continue
358
359                diagonal = 1.0 + self.dt * kappa * (dx2_inv + dy2_inv)
360                x_im1 = -0.5 * self.dt * kappa * dx2_inv
361                x_im2 = 0.0
362                if i == 1:
363                    diagonal += 0.5 * self.dt * beta_x * dx_inv
364                    x_im1 -= 0.5 * self.dt * beta_x * dx_inv
365                else:
366                    diagonal += 0.75 * self.dt * beta_x * dx_inv
367                    x_im1 -= self.dt * beta_x * dx_inv
368                    x_im2 = 0.25 * self.dt * beta_x * dx_inv
369
370                if beta_y >= 0.0:
371                    diagonal += 0.5 * self.dt * beta_y * dy_inv
372                    y_jm1 = (
373                        -0.5 * self.dt * kappa * dy2_inv
374                        - 0.5 * self.dt * beta_y * dy_inv
375                    )
376                    y_jp1 = -0.5 * self.dt * kappa * dy2_inv
377                else:
378                    diagonal -= 0.5 * self.dt * beta_y * dy_inv
379                    y_jm1 = -0.5 * self.dt * kappa * dy2_inv
380                    y_jp1 = (
381                        -0.5 * self.dt * kappa * dy2_inv
382                        + 0.5 * self.dt * beta_y * dy_inv
383                    )
384
385                block[row, row] = diagonal
386                block[row, index(i + 1, j)] = -0.5 * self.dt * kappa * dx2_inv
387                block[row, index(i - 1, j)] = x_im1
388                block[row, index(i, j - 1)] = y_jm1
389                block[row, index(i, j + 1)] = y_jp1
390                if i >= 2:
391                    block[row, index(i - 2, j)] = x_im2
392
393        return scipy.sparse.block_diag(
394            [block.tocsr() for _ in range(4)], format="csr"
395        )

397    def _reaction_jacobian(
398        self, state_flat: np.ndarray, scaled_activation_energy: float
399    ) -> scipy.sparse.csr_matrix:
400        state = state_flat.reshape((4, self.nx, self.ny))
401        theta = state[3]
402        if np.any(theta <= 0.0):
403            raise FloatingPointError("temperature became nonpositive during the solve")
404
405        rho = self.density
406        weights = self.molecular_weights
407        activation_energy = scaled_activation_energy * 1.0e3
408        exponential = np.exp(
409            -activation_energy / (self.gas_constant_times_temperature_scale * theta)
410        )
411        h2_concentration = rho * state[0] / weights[0]
412        o2_concentration = rho * state[1] / weights[1]
413
414        prefactor = self.reaction_prefactor * exponential
415        rate = h2_concentration**2 * o2_concentration * prefactor
416        d_rate_d_h2 = (
417            2.0
418            * (rho / weights[0])
419            * h2_concentration
420            * o2_concentration
421            * prefactor
422        )
423        d_rate_d_o2 = (rho / weights[1]) * h2_concentration**2 * prefactor
424        d_rate_d_theta = rate * activation_energy / (
425            self.gas_constant_times_temperature_scale * theta**2
426        )
427
428        d_rate_d_h2 *= self._reaction_mask
429        d_rate_d_o2 *= self._reaction_mask
430        d_rate_d_theta *= self._reaction_mask
431
432        block_size = self.nx * self.ny
433        local = np.arange(block_size, dtype=int)
434        rows = []
435        cols = []
436        data = []
437
438        for species in range(4):
439            if species < 3:
440                coefficient = (
441                    -self.stoichiometric_coefficients[species]
442                    * weights[species]
443                    / rho
444                )
445            else:
446                coefficient = (
447                    -self.stoichiometric_coefficients[2]
448                    * weights[2]
449                    / rho
450                    * self.heat_of_reaction_scaled
451                )
452
453            row = species * block_size + local
454            rows.extend([row, row, row])
455            cols.extend(
456                [
457                    0 * block_size + local,
458                    1 * block_size + local,
459                    3 * block_size + local,
460                ]
461            )
462            data.extend(
463                [
464                    coefficient * d_rate_d_h2.reshape(-1),
465                    coefficient * d_rate_d_o2.reshape(-1),
466                    coefficient * d_rate_d_theta.reshape(-1),
467                ]
468            )
469
470        return scipy.sparse.csr_matrix(
471            (np.concatenate(data), (np.concatenate(rows), np.concatenate(cols))),
472            shape=(4 * block_size, 4 * block_size),
473        )
474
475    def _newton_solve(
476        self,
477        previous_state: np.ndarray,
478        previous_rhs: np.ndarray,
479        linear_jacobian: scipy.sparse.csr_matrix,
480        kappa: float,
481        scaled_activation_energy: float,
482        beta_x: float,
483        beta_y: float,
484    ) -> np.ndarray:
485        iterate = previous_state.reshape(-1).copy()
486        residual = self._residual(
487            iterate,
488            previous_state,
489            previous_rhs,
490            kappa,
491            scaled_activation_energy,
492            beta_x,
493            beta_y,
494        )
495        initial_norm = np.linalg.norm(residual)
496        target = (
497            self.newton_absolute_tolerance
498            + self.newton_relative_tolerance * initial_norm
499        )
500        if initial_norm <= target:
501            return iterate.reshape(previous_state.shape)
502
503        for iteration in range(1, self.newton_max_iterations + 1):
504            reaction_jacobian = self._reaction_jacobian(
505                iterate, scaled_activation_energy
506            )
507            # Crank-Nicolson contributes one half of the new-state RHS Jacobian.
508            jacobian = linear_jacobian - 0.5 * self.dt * reaction_jacobian
509            update = scipy.sparse.linalg.spsolve(jacobian, -residual)
510            if not np.all(np.isfinite(update)):
511                raise RuntimeError(
512                    "Newton linear solve produced non-finite values at iteration {}".format(
513                        iteration
514                    )
515                )
516            iterate += update
517            residual = self._residual(
518                iterate,
519                previous_state,
520                previous_rhs,
521                kappa,
522                scaled_activation_energy,
523                beta_x,
524                beta_y,
525            )
526            residual_norm = np.linalg.norm(residual)
527            if not np.isfinite(residual_norm):
528                raise RuntimeError(
529                    "Newton residual became non-finite at iteration {}".format(iteration)
530                )
531            if residual_norm <= target:
532                return iterate.reshape(previous_state.shape)
533
534        final_relative = np.linalg.norm(residual) / max(
535            initial_norm, np.finfo(float).tiny
536        )
537        raise RuntimeError(
538            "Newton solver failed to converge in {} iterations; "
539            "final relative residual={:.3e}".format(
540                self.newton_max_iterations, final_relative
541            )
542        )
543
544    def solve(
545        self,
546        kappa: float,
547        scaled_activation_energy: float,
548        beta_x: float,
549        beta_y: float,
550    ) -> Tuple[np.ndarray, np.ndarray]:
551        """Integrate the flame model and return ``(states, times)``.
552
553        ``states`` has shape ``(num_snapshots, 4, nx, ny)``. The temperature
554        component is nondimensional; multiply ``states[:, 3]`` by
555        :attr:`temperature_scale` to obtain kelvin.
556        """
557        kappa, scaled_activation_energy, beta_x, beta_y = self._validate_parameters(
558            kappa, scaled_activation_energy, beta_x, beta_y
559        )
560        linear_jacobian = self._build_linear_residual_jacobian(
561            kappa, beta_x, beta_y
562        )
563
564        state = self.initial_state()
565        states = [state.copy()]
566        times = [0.0]
567
568        for step in range(1, self.num_steps + 1):
569            previous_state = state.copy()
570            previous_rhs = self._linear_rhs(
571                previous_state, kappa, beta_x, beta_y
572            ) + self._reaction_rhs(previous_state, scaled_activation_energy)
573            state = self._newton_solve(
574                previous_state,
575                previous_rhs,
576                linear_jacobian,
577                kappa,
578                scaled_activation_energy,
579                beta_x,
580                beta_y,
581            )
582            if step % self.snapshot_stride == 0 or step == self.num_steps:
583                states.append(state.copy())
584                times.append(step * self.dt)
585
586        return np.stack(states, axis=0), np.asarray(times)
587
588
589def extract_temperature_sensors(
590    states: np.ndarray,
591    spatial_stride: int = 4,
592    temporal_stride: int = 1,
593    temperature_scale: float = 1.0,
594) -> np.ndarray:
595    """Extract a flattened temperature-sensor QoI from a state history.
596
597    Parameters
598    ----------
599    states:
600        State history with shape ``(num_snapshots, 4, nx, ny)``.
601    spatial_stride:
602        Sample every ``spatial_stride`` grid points in each spatial direction.
603    temporal_stride:
604        Sample every ``temporal_stride`` stored snapshots.
605    temperature_scale:
606        Optional multiplicative scale. Use ``300.0`` to convert the default
607        nondimensional temperature to kelvin.
608    """
609    states = np.asarray(states)
610    if states.ndim != 4 or states.shape[1] != 4:
611        raise ValueError("states must have shape (num_snapshots, 4, nx, ny)")
612    if spatial_stride < 1 or temporal_stride < 1:
613        raise ValueError("sensor strides must be at least 1")
614    if not np.isfinite(temperature_scale) or temperature_scale <= 0.0:
615        raise ValueError("temperature_scale must be finite and positive")
616
617    temperature = states[
618        ::temporal_stride, 3, ::spatial_stride, ::spatial_stride
619    ]
620    return (temperature_scale * temperature).reshape(-1)

11class H2AirFlameQoiModel:
12    """Sensor-based ``QoiModel`` wrapper around :class:`H2AirFlame`.
13
14    The QoI consists of nondimensional temperature samples on regular spatial
15    and temporal strides. Full state histories are saved to each run directory
16    so the same FOM evaluations can also be reused for ROM construction.
17    """
18
19    parameter_names = H2AirFlame.parameter_names
20
21    def __init__(
22        self,
23        nx: int = 25,
24        ny: int = 13,
25        dt: float = 1.0e-4,
26        t_end: float = 5.0e-3,
27        snapshot_stride: int = 10,
28        spatial_sensor_stride: int = 4,
29        temporal_sensor_stride: int = 1,
30    ) -> None:
31        self._model_kwargs = {
32            "nx": nx,
33            "ny": ny,
34            "dt": dt,
35            "t_end": t_end,
36            "snapshot_stride": snapshot_stride,
37        }
38        self.spatial_sensor_stride = int(spatial_sensor_stride)
39        self.temporal_sensor_stride = int(temporal_sensor_stride)
40        if self.spatial_sensor_stride < 1 or self.temporal_sensor_stride < 1:
41            raise ValueError("sensor strides must be at least 1")
42
43    def populate_run_directory(self, run_directory: str, parameter_sample: Dict) -> None:
44        """Create the run directory required by the workflow model protocol."""
45        del parameter_sample
46        os.makedirs(run_directory, exist_ok=True)
47
48    def _parameters(self, parameter_sample: Dict):
49        missing = [name for name in self.parameter_names if name not in parameter_sample]
50        if missing:
51            raise KeyError(
52                "parameter_sample is missing required keys: {}".format(missing)
53            )
54        return [float(parameter_sample[name]) for name in self.parameter_names]
55
56    def run_model(self, run_directory: str, parameter_sample: Dict) -> int:
57        """Run the flame model and save states, times, parameters, and QoI."""
58        model = H2AirFlame(**self._model_kwargs)
59        parameters = self._parameters(parameter_sample)
60        states, times = model.solve(*parameters)
61        qoi = extract_temperature_sensors(
62            states,
63            spatial_stride=self.spatial_sensor_stride,
64            temporal_stride=self.temporal_sensor_stride,
65        )
66        np.savez(
67            os.path.join(run_directory, "solution.npz"),
68            states=states,
69            times=times,
70            qoi=qoi,
71            parameter_names=np.asarray(self.parameter_names),
72            parameters=np.asarray(parameters),
73        )
74        return 0

76    def compute_qoi(self, run_directory: str, parameter_sample: Dict) -> np.ndarray:
77        """Read and return the flattened temperature-sensor QoI."""
78        del parameter_sample
79        with np.load(os.path.join(run_directory, "solution.npz")) as data:
80            return np.asarray(data["qoi"], dtype=float)
