Indices and diagnostics for the fixed-count multifidelity estimate.

Indices have shape (number of parameters, number of QoIs). Coefficients and pilot correlations have one row for the variance, followed by the first-order and total-effect numerator rows in parameter order. Coefficients apply to terms computed from QoIs rescaled by the corresponding fidelity’s QoI scale. A component flagged in used_high_fidelity_only has the single-fidelity indices from the high-fidelity production design.

Samples, QoIs, and timings are ordered by pick-freeze block (A, B, and AB_i in parameter order). Within each low-fidelity production block, the first high-fidelity sample count rows match the high-fidelity block.

romtools.workflows.uq.multifidelity_sobol.run_multifidelity_sobol_indices(high_fidelity_model, low_fidelity_model, parameter_space, absolute_work_dir, number_of_high_fidelity_base_samples, number_of_low_fidelity_base_samples, pilot_sample_count=16, random_seed=1, high_fidelity_evaluation_concurrency=1, low_fidelity_evaluation_concurrency=1, overwrite=False, dispatcher=None, *, dry_run=False)[source]#

Estimate high-fidelity Sobol indices using paired low-fidelity runs.

All counts refer to base rows and must be powers of two of at least two. The low-fidelity production design must be at least as large as the high-fidelity design. An independently scrambled paired pilot fits a control coefficient for each term and QoI component. The pilot is additional to the specified production sample counts. Both models must return the same deterministic QoI components at independent scalar inputs.

For each term, the correction adds the pilot coefficient times the difference between the full and paired low-fidelity production means to the high-fidelity production mean. Ratios are formed after correction. A QoI with a nonpositive variance, a nonfinite estimate, or no active correction uses its high-fidelity-only estimate.

With d inputs, each fidelity runs (production count + pilot count) * (d + 2) evaluations. Successful evaluations can be reused by rerunning with the same design. Set overwrite=True when a model or QoI changes. Dry runs prepare both designs at both fidelities. Completed runs write multifidelity_sobol_stats.npz under absolute_work_dir.
